DAYFLOW AI - PROFILE MAKER + DIET PLANNER UPDATE

Files in this folder:
- index.html
- style.css
- script.js

INSTALLATION
1. Make a backup copy of your current DayFlow AI project folder first.
2. Put these three files together in the same project folder.
3. If Windows asks whether to replace existing files, replace index.html, style.css, and script.js in the BACKUP-FREE working copy only after keeping your backup.
4. Open index.html in your browser, or run your existing local server and open its local address.
5. Use the top navigation to open Diet Planner and My Profile.

WHAT IS INCLUDED
- Keeps the current daily task planner, points, and free Demo AI Coach.
- Adds navigation, a Profile Maker, profile picture upload, theme choices, goal and bio fields.
- Adds seven-day example meal ideas, dietary preference filters, allergy/exclusion text filters, simple recipes, saved meals, and completion checkmarks.
- Adds progress cards and achievement badges.

IMPORTANT LIMITATIONS
- Profile and meal data are saved in this browser on this device; this is not an online account and does not sync between devices.
- The meal suggestions are examples, not medical nutrition advice. The basic text filter cannot guarantee food is safe for an allergy. Always check labels and cross-contact risks.
- The website has not yet been tested on your own computer/browser. Please test the navigation, profile saving, image upload, meal filtering, saving, and completion before we continue to the next stage.
